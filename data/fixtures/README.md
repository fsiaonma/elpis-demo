# 脱敏样例与课程 fixture 说明

本目录存放**可进 git** 的脱敏说明、知识片段与岗位种子 SQL 等 fixture，供课程演示与 Eval 复现环境使用。

## 来源与用途

- **样例简历**：由讲师从过往辅导案例中**手工脱敏**后手动放入（本仓库不生成假简历正文）。
- **岗位种子**：通过 `part4.sql` 导入 MySQL `zteam.t_job`（约 180 条），不在页面上录入。
- **rubric / 知识片段**：后续章节从此目录或 `data/knowledge/` 灌入向量库。

## 脱敏口径

放入本目录或用于演示前，须确保：

1. **身份标识**：姓名、手机号、邮箱、住址、身份证号等全部替换为虚构信息或删除。
2. **公司与项目**：真实雇主名、未公开项目名、内部系统名改为泛化描述。
3. **链接与附件**：去掉可反查身份的个人 GitHub、作品集 URL、二维码等。
4. **投毒样例**：用于 Guardrail 演示的文件须单独标注，不与正常样例混放。

## 与 `data/resumes/` 的区别

| 目录 | 内容 | 是否进 git |
|------|------|:----------:|
| `data/fixtures/` | 讲师提供的脱敏说明与 fixture | **进** |
| `data/resumes/` | 用户实际上传的简历原文件 | **不进**（见 `.gitignore`） |

真实简历原件只落 `data/resumes/<id>/原文件名`，元数据真源为 MySQL `zteam.t_resume`。
