## 收口验收

> **留到 V36 / T21 最后一节当堂做**，六条全过才算 Part4 完成。

1. **端到端：** 从简历库上传 PDF → 点「分析」→ 10 分钟内报告页同时出现「六维雷达 + 综合分仪表盘 + Top 10 岗位条形图」。
2. **可复现：** 同一 `resume_id` + 同一岗位库快照，连续 3 次分析，六维分与综合分三次完全一致。
3. **可审计：** 任意一维分数点开，可见 rubric 文档片段 + 简历原文证据，且 evidence 可对应到 `t_resume` 字段或 `data/resumes/` 文件。
4. **可调权：** 仅修改 MySQL 中某岗位权重列，不改代码、不重启 MCP，重新分析后综合分变化。
5. **双出口：** `curl` 岗位 HTTP 接口返回条数 = 岗位库页面列表条数 = Agent MCP 查询条数（同一 `zteam.t_job`）。
6. **禁止项零违规：** eval 全绿 + 人工核对 [spec.md §9](./spec.md#9-禁止清单) 12 条，尤其：无模型 SQL、无模型 PDF 解析、无模型综合分、无 json 假库、简历原文未进 git。
